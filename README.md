# Freecam

A Freecam Mod for Ornithe 1.8.9<br>
Default keybind is "X"<br>

Should be undetectable by servers, but this is not guarenteed.

# Using
Grab the latest version from [Releases](https://github.com/dashnetworkxyz/Freecam/releases).
Add the JAR to your mods folder.

# Building
You'll need JDK 21 to compile Ornithe Patcher.<br>

run `gradlew build`
Compiled jar will be in `build/libs/`
